# Nuxt 2 HackerNews

This is a reproduction / copy of the [Nuxt 2 HackerNews](https://github.com/nuxt/hackernews/tree/nuxt2) clone.

## Building

Before building the example, update the `static/newrelic.js` file and replace `// BROWSER_AGENT_JS_SNIPPET` with the code snippet from your target Browser entity in New Relic.

Run `npm i` to install dependencies and `npm run dev` to run the project locally.
